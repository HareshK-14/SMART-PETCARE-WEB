## 🌟 What is Smart PetCare?

**Smart PetCare** is a full-stack AI-powered pet care platform that connects pet owners with veterinarians, provides intelligent health monitoring, and brings cutting-edge AI features to pet management. Whether it's booking a teleclinic appointment, scanning a pet's health via AI, or managing medical records — everything is in one place.

## 🚀 Getting Started

### Prerequisites
- **Node.js** 18+
- **Java** 17+
- **Maven** 3.9+
- **PostgreSQL** (or Supabase account)

---

### 🖥️ Frontend Setup

```bash
# Clone the repository
git clone https://github.com/HareshK-14/SMART-PETCARE.git
cd SMART-PETCARE/frontend

# Install dependencies
npm install

# Create environment file
cp .env.example .env
# Set VITE_API_URL=http://localhost:8080

# Start development server
npm run dev
```

🌐 Runs at: `http://localhost:5173`

---

### ⚙️ Backend Setup

```bash
cd SMART-PETCARE/backend

# Set environment variables
export SPRING_DATASOURCE_URL=jdbc:postgresql://your-db-host:5432/postgres?sslmode=require
export SPRING_DATASOURCE_USERNAME=your_username
export SPRING_DATASOURCE_PASSWORD=your_password
export JWT_SECRET=your_super_long_secure_jwt_secret_key_minimum_32_characters

# Run the application
./mvnw spring-boot:run
```

🚀 API runs at: `http://localhost:8080`

---

### 🐳 Docker (Backend)

```bash
cd backend
docker build -t smart-petcare-backend .
docker run -p 8080:8080 \
  -e SPRING_DATASOURCE_URL=your_db_url \
  -e SPRING_DATASOURCE_USERNAME=your_user \
  -e SPRING_DATASOURCE_PASSWORD=your_pass \
  -e JWT_SECRET=your_jwt_secret \
  smart-petcare-backend
```

## 🌐 API Overview

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/auth/signup` | POST | Register new user |
| `/api/auth/signin` | POST | Login & get JWT token |
| `/api/pets` | GET/POST | Manage pets |
| `/api/appointments` | GET/POST | Book & manage appointments |
| `/api/marketplace/products` | GET | Browse products |
| `/api/medical/records` | GET/POST | Medical records |
| `/api/vet/slots` | GET/POST | Vet availability |
| `/api/chatbot` | POST | AI chatbot response |
| `/api/admin/users` | GET | Admin user management |
| `/actuator/health` | GET | Service health check |

## 🗄️ Database

- **Provider:** Supabase (PostgreSQL)
- **Connection:** PgBouncer (Transaction mode, port 6543)
- **ORM:** Spring Data JPA / Hibernate
- **Auto-DDL:** Tables auto-created on first startup
- **Seeding:** Admin account auto-created on initialization
